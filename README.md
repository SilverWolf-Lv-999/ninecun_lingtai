# 九寸灵台

基于 **Minecraft 1.20.1 Forge** 的修仙主题模组。玩家从觉醒灵根、吐纳灵气开始，修习功法、炼制丹药、施展术法，并在五行环境与境界压制下逐步登临仙途。

> 项目仍在开发中，数值、内容与机制可能调整。

## 已实现内容

- **修炼体系**：灵根资质、魂魄、灵气、寿元、九大境界与突破。
- **五行环境**：金、木、水、火、土、阴阳、混沌属性，以及维度、群系、天气对灵气的影响。
- **功法与术法**：玉简烙印、熟练度、呼吸法、五行功法及御剑、遁术、防御法术等。
- **功法参悟**：支持通过 OpenAI 或 DeepSeek 对玩家填写的功法理解进行评分。
- **炼丹与资源**：炼丹炉、丹方、丹药、灵石矿与灵石品级。
- **储物戒指**：每枚戒指拥有独立的可交互储物空间。
- **战斗与生存**：元素伤害、境界压制、威压、渡劫、神游与夺舍等机制。

## 环境与前置

- Minecraft `1.20.1`
- Forge `47.4.22`
- Java `17`
- Curios API
- playerAnimator
- Inventory Tabs
- Filters API

Jade、JEI、Patchouli、WorldEdit 等为开发或辅助依赖，非基础游玩必需。

## 构建

```powershell
.\gradlew.bat build
```

构建产物位于 `build/libs/ninecun_lingtai-1.0.0.jar`。

## 配置与扩展

- 通用配置位于首次启动后生成的 `config/ninecun_lingtai-common.toml`。
- 若需启用 AI 功法参悟，请在配置文件的 `[ai]` 中填写服务商、API Key 和模型 ID；API Key 仅应保存在服务端。
- 功法和丹方使用服务端数据包加载，执行 `/reload` 后生效。

详细的数据格式见 [功法数据包格式](docs/功法数据包格式.md)。
