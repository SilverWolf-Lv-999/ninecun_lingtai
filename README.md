# 九寸灵台

[English README](README.en.md)

基于 **Minecraft 1.20.1 Forge** 的修仙主题模组。玩家将从觉醒灵根开始，吐纳天地灵气、参悟功法、修习术法、炼制丹药，并在五行环境、境界压制与渡劫试炼中一步步登临仙途。

> **开发状态：** 项目仍在持续开发中。版本号、数值、资源、数据格式和游戏机制都可能发生不兼容调整。

## 核心玩法

1. **觉醒灵根**：选择或获得金、木、水、火、土、阴阳、混沌等属性的灵根，并根据灵根长度确定资质。
2. **吐纳修炼**：在合适的环境中使用呼吸法吸收灵气，积累各系灵力，突破练气、筑基、金丹、元婴等境界。
3. **参悟功法**：通过玉简阅读功法内容，将自己的理解提交给 AI 评分；也可以通过数据包制作完全自定义的功法与熟练度体系。
4. **学习术法**：掌握御剑、遁术、排山倒海、防御法术等能力，并根据灵根与境界选择适合自己的修炼道路。
5. **炼丹与资源生存**：收集灵材、学习丹方，在炼丹炉中控制火候、消耗灵力炼制不同品级的丹药。
6. **探索与渡劫**：寻找灵石、探索界域、面对强敌，在渡劫、飞升、神游和夺舍等机制中承担修行的代价。

## 已实现系统

- **灵根与资质**：灵根元素、灵根长度、魂魄强度、神识范围与修炼承载能力。
- **境界与灵力**：九大境界、境界层数、突破条件、寿元、境界压制和境界带来的战斗成长。
- **五行环境**：金、木、水、火、土、阴阳、混沌属性；维度、群系、天气、地形和周围环境会共同影响灵气浓度。
- **功法与玉简**：呼吸法、功法兼容属性、功法前置条件、AI 参悟评分、熟练度、功法层级和魂魄烙印。
- **术法与移动**：元素攻击、御剑术、遁光/踏空、防御法术、威压、排山倒海等战斗与移动能力。
- **炼丹与丹方**：炼丹炉、主药/次药/辅药槽位、火候控制、丹药品阶、丹毒与丹方学习。
- **灵石与灵植**：灵石矿、天/地/人三品灵石，以及灵植、灵材和相关资源体系。
- **储物戒指**：每枚戒指拥有独立的可交互储物空间，并支持沉浸式操作模式。
- **生灵修炼**：部分生物、村民和怪物可以拥有灵根、修炼和境界成长。
- **渡劫与生死**：雷劫、防御资源、飞升相关流程、神游、夺舍和不同境界下的复生机制。
- **三千界与界域**：动态界域、跨界探索、界域通知和重生位置等系统。
- **界面与兼容**：修炼信息、功法库、丹方库、数值自控、Jade 信息提示和 JEI 炼丹配方展示。

## 安装与前置

### 玩家运行所需

请为 **Minecraft 1.20.1** 安装 **Forge 47.4.22 或兼容的 Forge 47 版本**，并将模组及其依赖放入 `mods` 文件夹。

当前项目实际使用的主要依赖如下：

- **Curios API**
- **playerAnimator**
- **GeckoLib**
- **Inventory Tabs**（客户端界面依赖）

以下模组用于可选功能、信息展示、配方查看或开发辅助，不属于基础玩法的核心依赖：

- **Filters API**：创意物品栏筛选兼容。
- **Jade**：信息提示集成。
- **JEI**：炼丹配方查看与配方界面集成。
- **Patchouli**：开发/说明书相关内容。
- **WorldEdit**：开发和世界编辑辅助。

多人游戏时，九寸灵台的服务端逻辑和客户端界面都需要匹配版本；请不要只更新其中一侧。具体依赖版本以 `gradle.properties`、模组发布包和对应依赖的下载页面为准。

## 第一次启动

1. 安装 Minecraft、Forge、九寸灵台和上述必要依赖。
2. 启动游戏或专用服务器并进入世界。
3. 首次启动后，Forge 会在 `config/` 中生成：
   - `ninecun_lingtai-common.toml`：服务端和通用玩法配置。
   - `ninecun_lingtai-client.toml`：客户端渲染配置。
4. 在游戏内通过按键、物品和界面开始觉醒灵根、阅读玉简并进行修炼。
5. 如果修改了功法或丹方数据包，执行 `/reload` 使服务端重新加载数据。

## AI 功法参悟

AI 参悟是可选功能，不配置 AI 时仍可以游玩其他修炼、战斗和炼丹内容。启用时请只在**服务端**编辑 `config/ninecun_lingtai-common.toml`：

```toml
[ai]
provider = "OPENAI" # OPENAI 或 DEEPSEEK
apiKey = ""
model = ""
```

注意事项：

- `provider` 目前支持 `OPENAI` 和 `DEEPSEEK`。
- `apiKey` 和 `model` 必须填写服务商提供的有效值。
- API Key 只应保存在服务端配置中，不要提交到 Git，也不要通过截图或日志公开。
- 模组不会把 API Key 通过网络包同步给客户端，但服务器管理员仍需自行保护配置文件。
- AI 服务不可用、配置缺失或请求失败时，相关参悟操作可能无法完成。

## 数据包与扩展

功法使用服务端数据包注册，文件路径为：

```text
data/<命名空间>/techniques/<路径>.json
```

例如：

```text
data/example/techniques/sword/azure_sword.json
```

对应的功法 ID 为 `example:sword/azure_sword`。功法正文、兼容灵根、境界要求、前置功法、AI 评分规则、熟练度层级和效果处理器都可以在 JSON 中定义。编辑后执行 `/reload` 即可重新加载。

完整字段说明与示例见 [功法数据包格式](docs/功法数据包格式.md)。炼丹配方同样通过服务端数据加载，内置示例位于 `src/main/resources/data/ninecun_lingtai/alchemy_recipes/`。

对于其他模组或扩展开发者，项目提供了培养、灵根、灵力、元素、术法、功法和炼丹等 API；功法效果可以通过 `TechniqueEffectApi.register` 注册处理器。API 仍处于演进阶段，升级时请同时检查源码和数据格式。

## 构建项目

项目使用 Gradle Wrapper。Windows 下执行：

```powershell
.\gradlew.bat build
```

构建产物位于：

```text
build/libs/ninecun_lingtai-1.0.0.jar
```

开发环境还可以使用 ForgeGradle 提供的 `runClient`、`runServer` 等任务。构建或运行开发环境前，请确保 Java 17 可用，并让 Gradle 能够访问项目声明的 Maven 仓库。
