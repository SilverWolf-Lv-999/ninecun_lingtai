# 灵气
计量单位为“点”。灵气修炼为练气至元婴修行的一种方式，这些境界都必须要有灵气

# 混沌气
计量单位为“缕”。混沌气为化神期所需要修行的气体，每100点灵气可以凝结出一缕混沌气，境界越高所需的越多，化神二重天每500点灵气凝结出一缕混沌气。
化神九重天则需要10000点灵气才能凝结出一缕混沌气。但容量不变

# 天道法则
合道至大乘期所的修行方式，计量方位为“道”。领悟10道法则进入合道一重天，900道法则进入合道九重天。
1000道法则进入炼虚，3000道法则进入大乘一重天。修炼方式为枯坐，以魂魄强度来决定法则领悟速度，一星魂魄强度每40分钟凝结出一道天道法则

# 仙元
大乘期修炼方式，计量单位为“滴”。从此时开始天道法则不再提升，开始凝练仙元。大乘九重天需要凝练八十一滴仙元，凝练完成后可以选择突破仙。凝练仙元的所需时间会越来越长，大乘一重天凝练一滴仙元的时间为3分钟，大乘二重天则为10分钟。成指数级上升。

# 劫
仙的修炼方式。一劫仙人要突破到二劫仙人，需要等待现实时间100小时，二劫仙人突破到三劫仙人需要120小时，八劫仙人突破到九劫仙人需要700小时。以上为一星魂魄强度的情况，魂魄强度越高所需时间越短
