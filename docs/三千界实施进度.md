## 第 2 步：动态界域加载与卸载
状态：已完成

已交付：

- `common/realm/ThreeThousandRealmManager.java`：从存档的 `data/ninecun_lingtai/three_thousand_realms.json` 加载元数据，按持久化 ID、展示名和独立种子动态构造 `ServerLevel`，并注册到服务端维度表。
- 动态加载时复用主世界的维度类型与生成器，调用 `markWorldsDirty()` 并发出 `LevelEvent.Load`，使服务端将界域作为正常加载的维度处理。
- `common/realm/ThreeThousandRealmSeedContext.java` 与 `mixin/common/realm/ServerLevelRealmSeedMixin.java`：在构造期隔离界域种子，保证 `ServerLevel#getSeed()`、随机状态和 `StructureCheck` 使用该界域的独立种子。
- `common/event/ThreeThousandRealmEventHandler.java`：在服务端启动前初始化管理器，在服务端 END tick 检查空闲界域，在服务器停止后清理运行时管理器。
- 空界连续达到 `threeThousandRealms.unloadDelayTicks`，且没有玩家和强制加载区块时，发出 `LevelEvent.Unload`、保存、从服务端维度表移除并关闭 `ServerLevel`。
- `META-INF/accesstransformer.cfg`：开放 `MinecraftServer.storageSource`，供运行时创建 `ServerLevel` 使用。

验证：

- 执行 `.\gradlew.bat test --rerun-tasks`，全部测试通过。
- 执行 `.\gradlew.bat build`，构建成功。
- `git diff --check` 通过，无空白错误。
- 检查 `run/logs/latest.log`，未发现本模组的 `MixinApply`、`InvalidInjection` 或注入失败。

运行时限制：

- 当前 `run/mods` 含有仅客户端模组，专用服务器启动会被 BetterGrassify、Oculus 和 Inventory Tabs 的客户端类加载错误阻断；因此动态创建和卸载的完整专服回归需在第 5 步移除这些模组后执行。

## 第 4 步：跨维度返回位置 JSON 持久化
状态：已完成

已交付：

- `common/player/PlayerThreeThousandRealmReturnPosition.java`：定义玩家离开界域时的界域 ID、X/Y/Z 坐标和朝向数据，并拒绝非有限数值。
- `common/player/PlayerThreeThousandRealmReturnState.java`：以 `formatVersion: 1` 将玩家 UUID 与返回位置持久化到 `world/data/ninecun_lingtai/three_thousand_realm_player_returns.json`；使用 UTF-8、临时文件原子替换写入，坏条目会单独忽略。
- `common/realm/ThreeThousandRealmManager.java`：离开已管理界域前写入当前位置；当外部维度的回程目标为主世界且存在记录时，动态加载原界域并使用保存的坐标和朝向传送。成功回归后删除记录；不存在的界域记录会丢弃并继续原主世界传送。
- `mixin/common/realm/ServerPlayerRealmReturnMixin.java`：拦截 Forge 的 `ServerPlayer#changeDimension(ServerLevel, ITeleporter)`。从界域离开到任意非界域时保存位置；回到主世界时改为返回保存的界域位置。返回位置持久化失败会取消本次离开，避免玩家失去可恢复的位置。
- `ninecun_lingtai.mixins.json`：注册服务端通用返回位置 Mixin。由于目标方法为 Forge 新增且运行时名称保持 `changeDimension`，该注入明确使用 `remap = false`。

验证：

- 执行 `.\gradlew.bat test --tests net.seraphina.ninecun_lingtai.common.player.PlayerThreeThousandRealmReturnStateTest --rerun-tasks`，JSON 写入、重新加载、删除、坏 UUID、外部命名空间和非有限数值校验通过。
- 执行 `.\gradlew.bat test --rerun-tasks`，全部测试通过。
- 执行 `.\gradlew.bat build`，打包和重混淆成功。
- 使用 Forge 47.4.22 的运行时 `srg.jar` 核对目标方法描述符与实际方法名；`git diff --check` 通过。

运行时限制：

- 专用服务器端到端回归仍受 `run/mods` 中 Oculus、Inventory Tabs 等客户端模组阻断，需在第 5 步使用干净服务端环境验证实际界域到下界/末地/模组维度再回归的完整流程。
