## 一、设计目标与原则（硬核六律）

1. **破境无侥幸**：大境界突破必须概率化。攒满灵力只是入场券，成功与否看天资、环境、丹药与道心。攒钱必过的境界不叫天堑。
2. **失败有代价**：破境失败、渡劫失败、走火入魔、死亡，四类失败共用一张分级惩罚表，代价随境界水涨船高，绝无"读档式重试"。
3. **资源必稀缺**：功法、丹方、法宝素材按品阶控制投放渠道。高阶孤本全服唯一，稀缺本身就是多人玩法。
4. **神魂有损伤**：魂魄不只是探测器的电池。灵魂受创留下魂伤，魂伤影响神识、参悟、渡劫，温养从升级条变成疗伤刚需。
5. **寿元是血条**：折寿是常态消耗而非遥远时钟。续命、复活、燃血、强行破境都动寿元，垂暮修士有真实的死亡焦虑。
6. **世界有敌意**：墓主会抹杀蝼蚁，散修会杀人夺宝，天道会记仇。世界不围着玩家转。
7. **服务端权威、数据驱动、不推翻现状**：沿用炼丹文档三原则——判定全在服务端；参数进 JSON 与 `CommonConfig`；已实装内容只叠加不重写。

### 1.1 硬核感的依据：四条感官通道

"硬核"不是数值大，是玩家心里真实产生的四种感受。每条都有成熟游戏先例背书，本文所有机制都必须至少击中其中一条，否则就是自嗨式加难度：

| 通道 | 心理学原理 | 先例 | 本设计落点 |
| --- | --- | --- | --- |
| 损失厌恶 | 失去的痛感约是等量获得快感的两倍；惩罚要"拿走已有的"，而不是"少给新的" | 魂系死亡掉魂、EVE 炸船不赔 | 破境失败烧灵力、折寿、魂伤、掉修为，全是从口袋里往外掏 |
| 不可逆 | 能读档重来的损失不是损失；不可逆才有重量 | 极限模式、Tarkov 战局内损失 | 魂飞魄散终结本局、孤本被夺不再有、寿元烧了不回来 |
| 信息敬畏 | 数字全透明会把敬畏变成算账；恰当的不透明让玩家对世界保持"摸不透"的敬畏 | 炼丹不显示进度条（本模组既有原则）、魂系不解释机制 | 破境只报"几成把握"、墓主不显示境界只给威压体感、心魔面板不可见、破禁不显示进度 |
| 社会见证 | 单机的失败是挫折，有观众的失败是叙事；修仙文学的核心张力就是"扬名与陨落都有人看" | 全服击杀播报（各大 PVP 服）、EVE 击杀邮件 | 突破播报已有，补齐失败播报、陨落播报、引劫播报、戒指湮灭播报 |

## 三、破境体系（硬核修正的核心）

### 3.1 小层与大境界的分野

- **小层突破**：保持确定性。灵力攒够即过，这是水磨功夫，无需赌命。
- **大境界突破**：概率化。灵力扣除照旧（入场券烧掉不退），成功与否掷骰。

### 3.2 大境界基准成功率

| 目标境界 | 基准成功率 | 定位 |
| --- | --- | --- |
| 筑基 | 80% | 入门坎，寻常人也过得去 |
| 金丹 | 55% | 结丹客，方为我辈人 |
| 元婴 | 35% | 陆地神仙，半数止步于此 |
| 化神 | 20% | 凡与神的分水岭 |
| 合道 | 12% | 融于天道 |
| 炼虚 | 8% | 破尽虚妄 |
| 大乘 | 5% | 最后一重天关 |
| 仙 | 3%（且必须渡飞升劫） | 万劫长存 |

### 3.3 成功率修正公式

```
最终成功率 = 基准 × 灵气质量系数 × 道心系数 × 功法品阶系数
           + 破境丹加成 + 瓶颈补偿
（结果夹在 [5%, 95%]，天道不给绝对的生，也不给绝对的死）
```

| 修正项 | 取值 | 说明 |
| --- | --- | --- |
| 灵气质量系数 | 凡浊 0.70 / 平和 1.00 / 清灵 1.15 / 极清 1.30 | 见 7.4 灵气质量 |
| 道心系数 | 1.0 − 杀孽值 × 0.002（下限 0.6） | 见 8.6 道心杀孽 |
| 功法品阶系数 | 黄 0.95 / 玄 1.00 / 地 1.08 / 天 1.15 | 主修功法品阶，见 8.4 |
| 破境丹加成 | +15% ~ +30%（加算），按丹药品阶 | 见 3.5 |
| 瓶颈补偿 | 每次失败 +3%，上限 +15% | 屡败屡战者天道垂怜 |

### 3.4 破境失败反噬

| 代价 | 数值 |
| --- | --- |
| 灵力散逸 | 本次扣除不退还，其余各池再散逸 60% |
| 肉身反噬 | 受最大生命 30% 真实伤害 |
| 魂伤 | +10（见 4.4） |
| 瓶颈期 | 3 游戏日内不可再次尝试破境 |
| 折寿 | 元婴以上失败额外折寿 2 年 |

### 3.5 破境丹重定位

现有 `PlayerBreakthroughDiscountData` 的需求折扣字段**保留**（向后兼容），但破境丹主效果改为成功率加成：

| 丹药 | 旧效果 | 新效果 |
| --- | --- | --- |
| 筑基丹 | 需求折扣 | 筑基成功率 +30% |
| 结金丹 | 需求折扣 | 金丹成功率 +25% |
| 凝婴丹（新） | — | 元婴成功率 +20% |
| 破神丹（新） | — | 化神成功率 +15% |

同种破境丹每次破境只吃一颗，重复服用无效（药力冲突）。

### 3.6 数值依据

- 文学惯例是"结丹十不存一"，直接照搬（10%）会把普通玩家劝退在金丹门口，所以取 55% 并把痛感转移到 3.4 的失败反噬上——概率温和、代价狠辣，玩家记住的是失败那次失去了什么，而不是概率数字。
- 瓶颈补偿（每败 +3%）是厄运保护：硬核不等于允许无限恶性循环，连败者获得"水磨功夫"的叙事台阶，这也符合文学里"屡试屡败终破境"的桥段。
- 上下限 [5%, 95%]：不存在必成的突破（大佬也要敬天），也不存在必败的死局（蝼蚁也有一线天机）。

### 3.7 破境体验设计

破境不是点按钮，是一场**有仪式感、有脆弱窗口、有观众**的赌局：

1. **引灵仪式（30 秒）**：发起大境界突破后强制盘坐，周身灵气涡旋粒子逐渐加密，天地灵气向玩家汇聚（所在区块灵气存量被急速抽吸）。仪式中受到任何攻击立即判失败并触发走火入魔判定（7.5）——多人下这 30 秒是最需要道友护法的时刻，也是仇家最好的下手窗口。
2. **把握感知（信息敬畏）**：仪式开始前界面只显示"此番破境，你约有 X 成把握"——最终成功率四舍五入到"成"，不显示精确百分比。魂强 5 星以上者额外显示是哪项修正在拖后腿（如"此地灵气浑浊"），低魂强者连这个都看不到，盲赌。
3. **成功演出**：冲天灵光柱（粒子束）、钟鸣音效、现有全服播报"玩家 踏入 境界"照旧——扬名时刻。
4. **失败演出**：灵气逆冲爆散粒子、玩家强制倒地 3 秒、七窍溢血红色粒子、心跳声由急促渐弱、屏幕短暂灰化（复用 `pressure_blur` 后处理）、全服播报"玩家名 冲击境界失败，气息一落千丈"——失败必须有观众，羞耻感是硬核的一部分（1.1 社会见证）。
5. **瓶颈期的日常提醒**：瓶颈期内打开修炼界面，境界名旁挂一道裂纹图标，鼠标悬停显示"道基未稳，X 日后方可再冲关"。

### 3.8 悟道印记（破境成功的三选一）

破境成功不只是数值升级，还是一次定制自身道途的时刻：

- 大境界破境成功的瞬间，玩家进入约 10 秒**悟道**状态（画面留白、时间感放缓），弹出三枚**悟道印记**三选一，选定即为永久被动。
- 印记池按资质灵根、主修功法与行为数据（战斗、炼丹、破禁、布阵等计数）加权抽取——杀伐果断者多见战斗印记，常年守着丹炉的多见丹道印记，梁上君子会撞见潜行印记。玩法塑造选项池，人各修各的道。
- 印记带升级链：**入门 → 精通 → 大成**。低境界选了入门，更高境界破境时对应精通才会入池——早期选择塑造后期选项，道途有连续性。
- 选定不可洗、不可换（落子无悔，1.1 不可逆原则）。
- 首期规模：战斗/丹道/阵禁/生存四类各 3-4 枚，约 15 枚，具体池子实装时定。

依据：鬼谷八荒每次大境界突破的"逆天改命"三选一是其构筑多样性的核心来源，"入门→精通"链让每次突破都自带期待感；此处将选项池与行为数据挂钩，比纯随机更贴"修的是自己的道"。

## 四、神魂体系

### 4.1 魂魄温养（已实装，成本修订）

- 魂强 1-7 星对应七魄，只能靠温养进度提升。
- 成长途径：炼魂功法打坐积累（凝魂诀每分钟 +2、炼魂真解每分钟 +6）、养魂丹一次 +40。
- **成本指数化修订**：每星所需进度 = `100 × 1.8^(当前星数−1)`。

| 升星 | 所需进度 | 折合养魂丹 |
| --- | --- | --- |
| 1→2 | 100 | 3 颗 |
| 2→3 | 180 | 5 颗 |
| 3→4 | 324 | 9 颗 |
| 4→5 | 583 | 15 颗 |
| 5→6 | 1050 | 27 颗 |
| 6→7 | 1889 | 需魂道机缘 |

- **魂道机缘**：6→7 星除进度外需消耗机缘之物（墓主残魂 / 秘境魂泉水，见第七、九章），否则进度封顶不涨。七魄圆满不该是刷丹刷出来的。

### 4.2 神识探测（已实装）

- 按键开关，开启期间持续耗灵（每秒 0.5 × 星数），耗尽自动收回。
- 半径 = 8 格 × 魂强星数 × 境界系数，上限 64 格。
- 八类过滤独立勾选：敌对 / 野兽 / 凡人村民 / 同道玩家 / 修士生物 / 普通矿脉 / 灵石矿脉 / 暗格容器。
- 匿踪规则：目标魂强 ≥ 探测者时不被标记。
- **反震修订**：神识扫到魂强高出 2 星及以上者，对方无感、自己吃反震魂伤 +10 并被强制收回神识——探人先掂量自己。

### 4.3 灵魂法术（已实装）

| 法术 | 形态 | 效果 | 风险 |
| --- | --- | --- | --- |
| 神识刺 | 单体 | 无视护甲/护体/守护灵，伤害 =（施法魂强 − 目标魂强 + 1）× 3 × 境界系数 | 目标魂强 ≥ 自己时法术反弹 |
| 摄魂音 | 自身范围 | 伤害 + 减速/虚弱/黑暗按魂强差分档 | 魂强 < 2 星强行施法自伤 |

### 4.4 魂伤体系（新增）

魂伤值 0-100，独立于生命与灵力的第三条暗槽。

**来源**：

| 事件 | 魂伤 |
| --- | --- |
| 被神识刺命中 | +15 |
| 被摄魂音命中 | +8 |
| 灵魂法术反噬/反弹 | +20 |
| 神识反震（撞上高手） | +10 |
| 破境失败 | +10 |
| 心魔劫中被心魔命中 | +5/次 |
| 墓主神识警告（境界差 1 档） | +5 |

**影响分档**：

| 魂伤 | 状态 | 效果 |
| --- | --- | --- |
| < 20 | 无碍 | 无 |
| 20-49 | 神思恍惚 | 神识半径 −30%，参悟评分 −10 |
| 50-79 | 魂魄震荡 | 神识半径减半，温养进度停滞，夜间随机惊醒（睡眠中断） |
| ≥ 80 | 魂飞魄散之危 | 灵魂法术全部不可用，每游戏日折寿 1 年，界面持续耳鸣音效 |

**恢复**：温养进度 1:1 优先抵扣魂伤（伤没好之前不涨星）；养魂丹每颗 −20 魂伤；7 星魂强自然恢复速度翻倍。温养由此从升级条变成疗伤刚需。

### 4.5 魂伤体验设计

魂伤是暗槽，不给精确数字条（信息敬畏），全靠身体感受知道自己伤得多重：

| 魂伤档 | 视觉 | 听觉 | 行为 |
| --- | --- | --- | --- |
| 20-49 神思恍惚 | 神识描边偶发闪烁失真 | 偶发短促耳鸣（复用 `pressure_ringing.ogg`） | 参悟界面提交时手写文字偶现错位感（评分照常，纯演出） |
| 50-79 魂魄震荡 | 视野边缘暗影蠕动（vignette，可复用 `soul_constellation` 暗色调） | 耳鸣频率明显加密 | 夜间睡眠随机惊醒：起身瞬间一道黑色人形剪影在视野角落一闪即逝——心魔的预演，吓的就是玩家本人 |

### 6.4 渡劫演出设计

渡劫是全服务器的公共事件，演出规格向"天地异象"看齐：

1. **引劫宣告**：引劫瞬间全服播报"玩家名 于 [坐标大致方位] 引动六九天劫"——渡劫地点公开。道友可赶来护法（帮清心魔、抗压阵外围怪），仇家可趁劫截杀（劫中玩家被外人击杀，属最经典的修仙横死）。风险与人脉同时具象化，这是 1.1 社会见证通道的最重头戏。
2. **天象压迫**：方圆百格天色压暗，雷云盘旋下压（复用 `tribulation_cloud` 着色器，云层高度随劫进度逐轮降低——越到后面天越"矮"，压迫感物理化）。百格内所有生物获得恐惧 AI（逃散），凡人村民关门闭户。
3. **雷击体感**：每一道劫雷落下前 0.5 秒，落点亮起雷纹预警圈——躲劫全靠走位与预判，蹲桩硬抗是下策（伤害按境界乘算，见既有实装）。
4. **心魔登场**：雷劫轮次结束、心魔劫开启时，天地骤然死寂（环境音全部消音 2 秒），随后心魔以玩家暗色剪影从影中走出，聊天框对渡劫者说话。台词从数据包读取并按行为数据填充："你杀 [玩家名] 时，手也是这么抖的""第 [N] 次冲关失败的滋味，还想再尝一遍吗"。台词库 JSON 化，服主可自行扩充。
5. **结局对称**：渡成——云开天光、金色雨粒子、全服播报踏入新境；渡败——雷云缓慢散去（不炸不响，天道懒得多看你一眼的冷漠感）、道基受损图标挂上境界名、全服播报"玩家名 渡劫失败"。

### 7.1 死亡代价与复活路线

| 条件 | 路线 | 代价 |

| 元婴及以上 | 燃元婴半血原地复活 | 修为跌至金丹，折寿 20% |

- 魂修/归体复用魂游 SoulEntity 载体；夺舍生物在玩家互夺底座上扩展目标类型。
- 接入：`LivingDeathEvent` 统一入口 + `PlayerCultivationData` + `EntityLifespanData`。

### 7.2 杀人夺宝：禁制体系（完整设计见《阵禁篇》）

禁制的本质是**神魂刻印**——玩家以自身神念主动为器物刻禁、为洞府点睛，完整设计独立成篇：`docs/阵禁篇.md`。要点概览：

- **神念锚位**：可维持的刻印总量 = 魂强 × 2，随身器禁与洞府大阵抢同一份神念；魂伤过重时刻印休眠。
- **器禁六种可叠层**：认主/传讯/隐匿/反噬/自毁/遗念，由外向内逐层破解，破解者事先不知道里面还有几层。
- **破解三条路**：力破（碾压线 = 强度 ×4）、巧破（锁纹对弈小游戏 + 神念指纹复仇线索）、器破（破禁锥 + 五行克制）。
- **死契**：主人死亡后禁制强度 ×1.5 持续 3 游戏日——杀人夺宝变成数日追逃叙事，不是秒杀秒拿。

### 7.3 修士墓穴

- 生成：Y < −10，深度与墓主境界正相关（合道浅层、大乘深层），每 128×128 区块约 1 座。
- 墓主三态机：沉睡（不 tick AI）→ 警告（外圈，全服警告语 + 威压 + 魂伤 +5）→ 破棺追杀（内圈或动棺椁）。
- 神识抹杀：玩家低于墓主两大境界及以上，追杀直接改为神识处决（复用 `realm_execution`）。
- 战利品按墓主境界分级：玄/地阶功法玉简、丹方残页、天字灵石、法宝素材、**墓主残魂**（魂道机缘，4.1）。
- 墓穴带机关与假棺，境界越高结构越复杂。追杀设范围上限与回巢机制。

### 7.4 区域灵气枯竭与灵气质量

**枯竭**（存量维度）：
- 区块灵气存量百分比，打坐吸收扣减所在及邻近区块；实际修炼浓度 = 环境浓度 × 存量。
- 存量总额约支撑单人满速修炼 3 游戏日；自然回复每游戏日 5%（约十比一的收支差）。
- 吸灵石不耗区域存量。稀疏存储：只记被消耗过的区块，回满即删。

**质量**（上限维度，与浓度正交）：
- 村庄、前哨等人口结构为负源，荒野高山为正；四档：凡浊 / 平和 / 清灵 / 极清。
- 质量决定破境成功率修正（3.3）与体魄累积速度（额外生命与物理减伤的来源）。
- 修炼信息界面加一行"灵气质量"。

### 7.5 走火入魔（新增）

| --- | --- |

### 7.6 寿元：第二血条

在自然流逝（一年三十六天）之外，折寿成为常态消耗：

| 折寿来源 | 数值 |
| --- | --- |

### 7.7 生存闭环体验设计

**死亡路线选择界面**：死亡瞬间画面定格转灰，正中浮现有资格的路线按钮（无资格的路线以灰字显示并标明缺什么——"燃元婴复活：需元婴期"，让玩家知道自己在为什么而修炼）。倒计时 30 秒，走沙漏动画。选择"魂魄归体"后以魂体视角（复用魂游的半透明渲染）飘回尸体，沿途所有生物对你视而不见——死过一次的世界格外安静。

**墓主的三段恐惧**：
1. 靠近外圈：屏幕朝墓穴方向的边缘渗入暗红色光晕（方向性提示，不给坐标），伴随一声极低的心跳；聊天框收到只有自己可见的警告："何方小辈，安敢扰吾清眠。"同时魂伤 +5——被高手神识扫过，本身就是伤。
2. 进入内圈：全服播报"玩家名 惊动了 [某地] 的沉眠大能"——你的贪婪全服务器都知道了，跑不跑得掉是你的事。
3. 神识抹杀（境界差 ≥2 大境界）：0.5 秒纯白闪屏，一声冷哼（新音效），死亡消息全服播报"玩家名 被一道神识抹去了形神"。不给任何反抗窗口——这条规则的存在本身，就是全服玩家对"境界差"最深刻的一课。

**戒指破禁赌局**：破禁者潜行长按戒指，戒指发光频率逐渐加快（不显示进度百分比，信息敬畏）；主人若在附近能听到自己戒指的嗡鸣（提示你的遗产正被人撬）。自毁触发时：湮灭爆音 + 黑洞收缩粒子 + 全服播报"玩家名 的储物戒指化为飞灰"——赌局结果全服见证，围观者自行体会该同情谁。

**灵气枯竭的体感**：打坐时吸入的灵气粒子随存量下降变得稀疏、色泽发灰；存量 < 30% 时打坐音效变干涩，界面浓度数字旁挂"衰"字角标；完全枯竭时打坐直接弹"此地灵气已竭"。不做方块变色（区块级色调修改代价过高），全部走粒子与 UI 通道。

**垂暮的重量**：剩余寿元 < 10% 起，年轮界面灰化并逐日龟裂加深；移动脚步声变沉；每个游戏日清晨收到一次仅自己可见的提示"你的大限还剩约 X 年"。修仙文学里老怪物的悲凉，要让玩家亲身尝到——然后把破境续命的赌注推到他面前（3.2 的概率表在垂暮者眼里完全是另一种东西）。

## 八、成长纵深

### 8.1 功法品阶（前置于炼器与自创）

- 黄/玄/地/天四阶各分下中上三品；品阶影响修炼速度倍率、法术威力上限、参悟门槛与破境成功率（3.3）。
- 存量功法数据包补 `grade` 字段，缺省按需求境界映射。

### 8.2 法宝与炼器

- 炼器炉复用炼丹炉多方位结构与火候框架；材料 = 矿物 + 妖兽素材 + 墓穴产出。
- 品阶：法器 / 灵器 / 宝器 / 仙器。
- 祭炼：滴血绑定，耗神识；魂强不足祭炼高阶法宝触发反噬（魂伤 +20）。未祭炼的法宝用不出全力。
- 本命法宝：每人一件，随境界成长解锁特效；主人死亡则蒙尘掉级。
- 飞剑并轨：御剑速度/耗灵/剑气 = f(剑品阶)。

### 8.3 阵法（完整设计见《阵禁篇》）

阵法与禁制同源（神魂为魂、灵力为血、结构为骨），完整设计见 `docs/阵禁篇.md`。要点概览：

- **三要素**：阵图（数据包 JSON，走稀缺链）+ 阵器（阵盘/阵旗/阵基）+ 布阵（实地几何摆放，精度定效率 80%-120%）。
- **首期七阵**：聚灵（对冲 7.4 枯竭）、护府、困灵、杀伐、幻、遮蔽（克神识与传讯禁）、引灵（供炼丹炼器）。
- **点睛**：布阵者耗神念锚位把阵升为"灵阵"（白名单/警报/联动），阵禁在此合体。
- **破阵三条路**：力破（打爆阵盘储能）、巧破（神识观灵力逆流找生门旗）、耗破（围而不攻烧其灵石）；全体系反制链闭环，没有绝对安全的布置。
- **洞府**：阵禁的毕业考，一座完整洞府吃 8-11 锚位；离线保护 ×2 但灵力只出不进，7 日后回落——地皮自然流转。

### 8.4 灵植栽培

- 灵田需灵气存量充足的区块开垦；生长速度吃浓度、品质吃质量。
- 极清灵气下小概率变异出高一阶药材，衔接高阶丹方。
- 灵力催熟加倍消耗区块存量——与枯竭系统硬取舍。

### 8.5 自创功法

- 大乘及以上开启；玩家撰写功法内容走参悟评分流程反向定品，成品写入玉简可传授他人——多人服务器的传承玩法。

### 8.6 道心与杀孽

- 杀孽：击杀凡人（村民）+3、同道修士（生物/玩家）+5，妖兽不计；上限 200。
- 影响：破境道心系数（3.3）、心魔强度（6.2）、被神识探测时呈血色标记（藏不住的煞气）。
- 消解：静心丹每颗 −5、闭关连续离线打坐折算、除魔任务（阶段三钩子）。

### 8.7 境界后期专属能力

| 境界 | 能力 | 要点 |
| --- | --- | --- |
| 合道 | 法则领域 | 半径 20 格，域内五行倍率按主人灵根重写，敌方施法耗灵翻倍 |
| 炼虚 | 虚空挪移 | 洞府锚点跨维度传送，高耗灵长冷却 |
| 大乘 | 一念化形 | 一分钟分身协战，继承部分法术 |

## 九、世界与终局

### 9.1 修士 NPC 与宗门

- 散修/宗门弟子按境界分布生成，可交易玉简丹药；**魔修散修会主动袭击高价值目标**（身上天阶功法/宝器者被神识锁定的概率高）——世界有敌意。
- 玩家宗门：创建/加入、贡献点、藏经阁（功法共享库，投放受稀缺链约束）、宗门任务（采药/除魔/护矿）。

### 9.2 坊市与灵石经济

- 坊市地表结构：丹阁/器阁/书阁 NPC 商铺，三品灵石分层定价；只卖黄阶与消耗品，稀缺链上游不放水。
- 拍卖行（多人）：墓穴产物、变异灵草、天阶孤本的流通出口。

### 9.3 秘境

- 世界随机限时裂隙，境界准入上限（防高打低刷宝）。
- 独立小维度：机关 + 困阵 + 妖兽守宝 + 限时撤离；集中投放法宝素材、高阶丹方、**魂泉水**（魂道机缘）。

### 9.4 妖兽与化形

- 妖兽境界化，掉妖丹（炼丹/炼器素材）；大妖（元婴级以上）概率化形为 NPC。
- 灵宠：驯服低阶妖兽，喂丹随主人成长；本命契约死亡反噬主人魂伤 +30。

### 9.5 飞升与仙界

- 大乘圆满主动引飞升劫（6.1 终形）；成功触发飞升演出，进入仙界维度。
- 仙界：仙灵气浓度质量双高但环境凶险，仙阶资源与仙器素材产地；"能自行修炼的怪物会随着飞升见到更多"在此兑现。
- 登仙后年轮隐去，寿元无限，"其灵永存"。
- 转世重修：仙界玩家自愿转世回主世界，从练气重修，保留一缕真灵（资质加成 + 少量功法残忆）——长线重玩机制。

## 十一、实施顺序与依赖

```
阶段零（硬核规则修正包，全部作用于已实装系统）
  破境概率化 ─→ 破境丹重定位
  渡劫冷却与劫后虚弱
  走火入魔
  魂伤体系 ─→ 温养成本指数化 / 神识反震
阶段一（生存闭环）
  死亡与复活路线 ─→ 戒指禁制夺宝
  修士墓穴 ─→ 墓主残魂（魂道机缘）/ 法宝素材备料
  灵气枯竭 + 灵气质量 ─→ 破境质量修正生效
  寿元第二血条 + 岁月盘
阶段二（成长纵深）
  功法品阶 ─→ 稀缺链落地 ─→ 自创功法
  炼器法宝 ─→ 本命法宝 / 飞剑并轨
  阵法（聚灵阵对冲枯竭）─→ 灵植栽培 ─→ 高阶炼丹闭环
  道心杀孽 ─→ 心魔即己强化
阶段三（世界终局）
  修士 NPC ─→ 宗门 / 坊市 / 拍卖行
  秘境（魂泉水）─→ 妖兽化形与灵宠
  飞升劫 ─→ 仙界 ─→ 转世重修
```

推荐节奏：阶段零最优先——它不加新内容，只把已有系统的规则拧硬，硬核感立竿见影；阶段一补完设定承诺；阶段二中炼器与阵法先行（墓穴产出需要消耗出口）；阶段三在多人需求明确后动工。

## 十二、跨模块风险清单

- **存档兼容**：区块存量、魂伤、杀孽、寿元扩展全部走增量 NBT 键，旧档缺键取默认值。
- **多人安全**：路线选择、破禁、拍卖、破境判定全部服务端裁决，客户端只发意图包；概率骰子只在服务端掷。
- **性能**：墓主沉睡态不挂 AI；区块存量稀疏存储；神识、阵法、领域扫描共用节流策略。
- **惩罚口径统一**：破境失败、渡劫失败、走火入魔、死亡四处惩罚共用同一张分级表源（配置），避免规则打架。
- **数值联动**：概率化破境 + 灵气质量 + 道心三者同时上线才成立，单独上概率化会被质疑纯赌运气——阶段零与 7.4 的质量维度要衔接紧凑。
- **上游合并**：新系统尽量新增文件，插点集中在注册表、事件总线与语言文件，降低与主仓库提交的冲突面。

## 十三、玩家旅程样例（硬核感的时间线验证）

设计是否成立，用一名普通玩家（五寸单灵根，多人服务器）的完整旅程来验证。主轴是**恐惧对象的迁移**：怕怪 → 怕失败 → 怕人 → 怕天。每个阶段玩家怕的东西在升级，这条线就是硬核修仙的体验骨架。

| 阶段 | 大约时间 | 关键体验 | 击中的通道（1.1） |
| --- | --- | --- | --- |
| 凡人 | 第 1 日 | 抽灵根：五寸中人之姿，亲眼看到服里有人抽出九寸天灵根被全服播报——出生即不公，修仙世界的第一课 | 社会见证 |
| 练气前期 | 第 1-3 日 | 找低洼荒野打坐；第一次在野外修炼被怪打断吃硬直，学会"清场再坐、下矿避人"；灵力被一次走火入魔散逸大半 | 损失厌恶 |
| 练气后期 | 第 4-7 日 | 常驻修炼点区块存量告衰，吸灵变慢，被迫搬家或买灵石——第一次体会"资源会枯竭" | 损失厌恶 |
| 冲击筑基 | 第 8 日 | 八成把握仍然失败一次：灵力烧光、倒地溢血、全服播报；三日瓶颈期里看着同期道友先一步筑基 | 损失厌恶 + 社会见证 |
| 筑基期 | 第 9-15 日 | 攒钱求购筑基丹无门（稀缺链），进人生第一座修士墓穴：外圈被墓主神识扫过魂伤 +5、耳鸣三日，拿了玄阶功法连夜跑路 | 信息敬畏 |
| 冲击金丹 | 第 16-20 日 | 为提破境成功率：寻极清之地、清杀孽、服结金丹；引灵仪式 30 秒请两位道友护法——第一次把命交给别人 | 不可逆 + 社会见证 |
| 金丹渡劫 | 第 20 日 | 三九劫全服播报，来了五个围观的、一个不怀好意的；劫云压顶时那个人动了手——护法道友拦下；渡成，踏入金丹的播报里带着劫后余生 | 全部四条 |
| 金丹以后 | — | 开始怕人：身上有玄阶功法和本命法宝坯子，死了戒指会被搜；也开始怕天：下一场是六九劫，心魔会当众念出你在筑基期干过的脏事 | 不可逆 + 社会见证 |

验证标准：如果实装后玩家的社区讨论集中在"哪里灵气好""谁渡劫了去看看""他戒指爆了没"，说明四条通道全部打通；如果讨论集中在"成功率怎么算的""数值卡在哪"，说明信息敬畏做漏了，回头查哪个数字被透明化了。
