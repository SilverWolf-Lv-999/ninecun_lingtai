# 劫难设计
1. 第一道劫难——像筑基突破金丹那样，渡九九八十一道雷劫。该雷劫造成的伤害会影响防御点数
2. 第二道劫难——根基。询问玩家对他所学习的功法的理解
3. 第三道劫难——问道。由天道向你问道，天道认为你对了，才能突破。

# 飞升触发条件？
类似筑基期突破金丹，飞升劫的触发为元婴突破化神

# 怎么写？
1. 先经历九九八十一道雷，且该雷能快速地削减防御点数和灵气储量，如果玩家开了防御法术会优先削减防御法术带来的东西
2. 随后是地劫，它会打开一个界面，风格依旧是那些界面，随后获取玩家学习过的所有的功法呀丹方呀啥的，还有对境界的感悟，分为十个问题提出
3. 最好是人劫，问道，界面风格依旧是那个界面，随后只有一个问题“何为道？”，十个问题内答完。
4. 全部完美完成后，即可飞升
