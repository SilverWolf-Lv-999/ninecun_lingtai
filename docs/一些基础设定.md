# 一、基础设定。

灵根元素有——金、木、水、火、土、阴阳、混沌。

灵根通过长度来确定资质，最长九寸，最短一寸，越长灵根越好，吸收灵力的速度越快。

灵力是有质量的，他们会自然下沉，地势越低的地方，灵力越浓郁。

村庄、林地府邸这种有大量人在的地方，灵力质量会很低。

而无人的区域，比如森林、高山，灵力质量很高。

灵力的质量决定体魄，和未来突破境界的概率。

灵力也会受到遮挡影响，无遮挡的，地势低的地方，灵力会更浓郁。

然后便是魂魄，魂魄强度关系到神识范围，玩家可以开关神识，开启后，神识范围内的指定方块、生物都可以直接看见，并通过一条线连接到准心处(都可以由玩家指定)。

魂魄强度也关系着对灵魂类功法的承载度。

玩家在一个区域呆的太久了，所有的灵气会随着玩家的持续吸收而逐渐枯竭。此时玩家只剩两个选择——吸收灵石或者搬家。

灵石可以通过和流浪商人交易、挖矿获得，或者打怪掉落。

灵石有天、地、人三个品种，灵力纯净到极点，为天字级灵石，越浑浊、驳杂不堪则越低。

天地间自然存在的灵气只有金、木、水、火、土五行，不存在阴阳灵气、雷灵气或混沌灵气。普通灵根只能吸收对应的五行灵气。每根独立灵根的灵力分别积累，但境界属于玩家，不属于灵根；玩家每次踏入下一小境界或大境界前，所有独立灵根都必须分别积满目标境界所需的灵力，突破时统一扣除。凡人踏入练气一层时，单灵根需要二十五点灵力；双灵根则两根各需二十五点、合计五十点，只有两根都圆满后玩家才能踏入练气一层。突破提示统一显示为“玩家名 踏入目标境界”。

阴阳灵根属于单灵根，可以感应并吸收全部五行灵气，但五行必须平衡；每次修炼只会将五行中能够同时等量吸收的部分化为阴阳灵力，不能依靠单一属性推进突破。

混沌灵根也属于单灵根，是万物之始。它会吸收全部五行灵气，将五种属性本次吸收的灵力总量直接相加并化为混沌气，不需要维持五行平衡；玩家界面与修炼数据统一显示为混沌气。废气、魔气、死气等并非天地灵气，但混沌灵根仍可在相应来源存在时将其转化为混沌气。

各个维度、群系和天气拥有不同的元素属性，并会按照五行相生相克改变当地各种灵气的浓度。最终浓度由维度、群系、天气倍率叠乘得出；倍率为零时，该属性灵气会被完全压制，无法看见和吸收。例如海洋完全属水，火灵气为零；下界完全属火，水灵气为零。降雨、降雪和雷暴只在露天且当地实际发生降水的位置生效。详细规则见《五行相生：木 → 火 → 土 → 金 → 水 → 木》。

关于功法，玩家需要自己理解功法内容，然后将理解的内容发送在特定的输入框内，让AI决定玩家的理解程度，然后来决定玩家是否应该学习好这个功法。

关于理解，AI会给玩家的理解进行评分，满分100分，如果玩家达成这个分数，直接进入该功法的小成；玩家的理解中，如果有类似“引气入膻中，走任脉，过三关”等等内容，则会大幅提高评分。

有些怪物、村民、生物也能修炼，少数动物可以直接化形。

能自行修炼的怪物很少，但会随着飞升见到更多。

世界中会随机刷新合道至大乘间的修士的墓穴，他们通常刷新在 Y 轴 \< -10下。

玩家靠近一定距离时，会惊动他们，对你发出警告。靠的太近时，他们会冲破棺材并追杀你。如果你境界和他们相差太大，他们会用神识直接杀死你(比如大乘修士看到你个区区金丹期的蝼蚁敢靠近他的地盘)。

修士的墓穴越高阶，也会越复杂。墓穴里有时候会刷好东西，墓主人的修为越高，东西越好。

玩家死亡时，会一定的境界。如果是极限模式下，且境界在金丹期，可以选择夺舍或魂修的形式继续游玩，如果是夺舍重生，修为会跌落到练气巅峰；魂修则需要从练气初期开始。元婴期，则可以消耗自己的元婴，直接原地半血复活，修为跌落至金丹。化神后，可以滴血复活，并跌落一个小境界，只要击杀你的人和你境界差距不会太大。但你还有最后一种选择——死亡后，魂魄返回肉体处，修复肉身。但你的时间会受到魂魄强度和肉身强度限制。

修士的境界差距越大，实力差距就越大，一层一重天。或许你练气巅峰还能碰瓷下筑基，但对方一旦到筑基中期，你打他就是挠痒痒，几乎造成不了伤害。

化神是凡与神之间极其重要的分水岭。无论玩家还是能够修炼的生物，只要攻击者达到化神期及以上，其攻击命中元婴期及以下目标时，都会直接跨越护盾、盔甲、药水、不死图腾与修为防御将目标一击抹杀；没有修为的生物同样视为化神以下。化神期及以上目标不受这条秒杀规则影响。

多人游戏下，玩家可以夺舍别的玩家，被夺舍的玩家将永久处于旁观者模式。

玩家、生物将会有“寿元”，寿元耗尽，生物将会被删除，玩家将处于旁观者模式。

一年为三十六天，并添加一个游戏道具，来决定是否加速游戏时间流逝，与是作用于单人还是群体，和加速多快。

玩家可以通过看自己的年轮，来知晓自己有多少岁。若登仙，年轮不见，其灵永存。

混沌灵根可以吸收任何形式的灵气，混沌灵根无论在哪都是主场，混沌灵根可以学习所有形式的功法。

# 二、境界与简介

1. 练气——一切之初，修士感应天地灵气，感应完成，尝试引气。引天地灵气入身，冲破自身窍穴，以窍穴为府，经脉为路，周天内寻，修魂淬体。寿元二甲子。
2. 筑基——练气如雨露浇花，筑基方只道高远。一入筑基境界，便是迈入了真正的修仙之途。筑基之基，是指人体丹田内的根基，也就是灵气修为的根本。修士在练气期经年积累, 体内灵气渐盈，终有一日灵气浓郁至极，便需开辟丹田，构筑灵基。此时若有奇妙功法相助，便可凝聚灵气，在丹田之处构造一座气府。此气府便是修士根基所在，故名筑基。寿元两百载
3. 金丹——结为金丹客，方位我辈人。金丹类似于纯粹武夫存储真气的气海丹田，能够将天地间缥缈驳杂的灵气化虚为实，固化其中，不再依靠周生洞府存储灵气。寿元五百载
4. 元婴——元婴者，元神外显，婴丹内化也。是于凡间飞升之前，修士所能达到的最高境界，故又称其为陆地神仙。寿元千余。
5. 化神——化神期，羽化成仙，元婴凝神也。是指凡间修士突破凡人极限，跻身神人境界的一个过程。一旦踏足化神期，便是跻身仙人之列，为一方天地之神明，与天齐寿，天地法则于我所用。
6. 合道——大道之上，人海茫茫，所求不过一个术法通天，永恒不朽。而妄图与天齐寿最好的方法无疑就是成为天，将自身融入天地无形的大道之中，化作天地的法则，成为天地的一部分化身。
7. 炼虚——合道者融于天，终究为天所缚。炼虚之境，乃反其道而行，以大智慧、大法力炼化虚空，破尽万法之虚妄，勘破天地之本源。修士至此，不再依附大道，而是超然其上，一念可改法则，一意可生造化，虚空生灭皆由我心。
8. 大乘——夫修仙之路，条条若星河倒悬。期间境界森罗，而大乘一境，尤为天地枢机，万物化境。此境超脱凡俗，凌驾阴阳，乃登仙途最后一重天关，亦为肉身凡胎蜕变为仙元道胎的终极之境。
9. 仙——仙者，非人非神，非道非法。乃修士历万劫、破九境、脱凡胎、证真我之后所成之果。仙者无名，无相，无形，无念，却可造化万物，颠倒阴阳，逆转生死，重塑乾坤。仙之一字，乃天地初开时第一缕灵光所化，万劫长存，永恒自在。至此，方知修仙之始，非为长生，而为不受一切所缚。
