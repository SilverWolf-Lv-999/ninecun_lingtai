# 炼丹的本质与体系重构
在修仙世界的物质基底中，炼丹术远非简单的药草熬煮，而是一种以炉火为媒介、以神识为引导的“物质炼金术”与“能量转化术”的完美统一。它不仅是药物提取的工艺，更是天地法则的微观演绎——于方寸丹炉之间，重现宇宙从混沌到秩序的创生过程。

## 一、炼丹的本质定义
炼丹，是以修士自身为“活丹炉”，以外丹炉鼎为“容器”，通过精准操控天地元气与神识之火，将各类灵材中的杂质剥离、能量重组、性质跃迁，最终凝结成远超原料本身价值的高能聚合体的过程。

炼丹的核心并非“提取有效成分”，而是 “促进物质发生质变” 

## 二、炼丹的要求
炼丹，至少需要神识，操纵灵火/牵引地火

## 三、炼丹炉
已经有了

## 四、丹方
玩家只有学习了丹方，才能用该丹方炼丹。

神话丹方中，不会说明炼制一炉丹药所需的时间、用量等等内容，只会说用xxx主药，xxx次药，xxx辅药，用的放入顺序和大概间隔。

丹药分品级(先是大区分，一阶最次，九阶最高；然后是小区分，一品最次，九品最高。显示就为诸如"九阶一品""八阶三品"。和丹方一样，对应境界的丹药对应境界才能用。但有些丹药是可以多境界使用的)，丹方也分品级(和丹药一样，但丹方对应的是境界，一阶对应练气，二阶对应筑基，以此类推，八阶就对应大乘，九阶对应仙。只有对应的境界才能学习并炼制对应的丹药)

## 五、炼制
按中国古代的“道家”的天、地、人设计，分为五个槽位：
1. 一个输入槽——主药：该槽位接收主药，且对数量有要求
2. 两个输入槽——次药：该槽位接收次药，一样对数量有要求
3. 两个输入槽——辅药：该槽位接收辅药，一样对数量有要求
4. 一个输出槽——丹药：该槽位为输出槽，输出丹药

## 六、UI设计
1. 和资质选择界面中的灵根属性一致排序，主药在最上面，中间两边为次要，下面两边为辅药，中间的阴阳图则换成输出槽。
2. 底部中心一个按钮——开始炼制，开始后，炼丹炉里的材料将无法取出，如果停止则会发生炸炉。
3. 开始炼制后，“开始炼制按钮”变成“结束炼制”，点击后可以停止炼制
4. 右下角有个进度条，为“火候”，玩家可以通过打火石为炼丹炉点火，此时进度条会显示持续时间，时间结束后进度条清零，且炼丹炉里的未炼制完成的丹药，也就是放进去的材料会化作飞灰，消失不见。玩家可以通过长按进度条消耗灵力来维持火候，丹方等级越高，消耗的灵力也越多，像境界一样指数级增长。
5. 开始炼丹后，如果丹药开始逐渐成型，则会在顶部提示 “一缕丹香从中飘出”，字是渐入渐隐的。
6. 根据玩家炼丹的时间、火候、环境(因为也要保持五行)来决定玩家炼制出的丹药是什么品阶，品阶越高，效果越好。
