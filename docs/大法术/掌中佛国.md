# 掌中佛国
## 主设定
1. 一个正常的维度
2. 被囚困的生物/玩家眼中，这就是个正常的维度， 看不到外面
3. 施法者可以看到佛国里面
4. 施法者可以选择生物/玩家并将他们丢入自己的佛国之中
5. 施法者可以对着佛国中的生物/玩家随意施法
6. 每个玩家的佛国都是独一无二的

## 选择器
1. 单选，可以将准心处的生物丢入佛国中
2. 多选，遍历周围一定范围的生物并自主选择丢入佛国

## 限制
1. 练气期施展最多影响到筑基期
2. 其它情况下只能对和自己同境界或低于自己境界的目标施展

## UI设计
1. 施法者释放掌中佛国后，打开一个Gui
2. Gui中，有个翻页页面，玩家可以左右翻页，查看里面的玩家
3. 施法者可以将自己四周的玩家/生物放入佛国中，也可以选定佛国中的玩家/生物放出来
4. 可以对生物/玩家进行多选操作

## 表现方式
1. 发出去的信息，只有施法者/自己/和自己在同一个“手掌”中的玩家能接收到
2. 被攻击方只能接收到来自自己/和自己在同一个“手掌”中的玩家/世界的网络包

## 他人视角(即被丢入、丢出佛国)
1. 自己四周变成白色并开始逐渐失去声音，白色转换成佛国中的景象，完成切换维度。这样可以杜绝加载页面
2. 开始进入/退出佛国时，自身将无法进行任何交互
