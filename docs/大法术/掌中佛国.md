# 掌中佛国
## 主设定
1. 一个正常的维度
2. 被囚困的生物/玩家眼中，这就是个正常的维度， 看不到外面
3. 施法者可以看到佛国里面
4. 施法者可以选择生物/玩家并将他们丢入自己的佛国之中
5. 施法者可以对着佛国中的生物/玩家随意施法
6. 每个玩家的佛国都是独一无二的

## 选择器
1. 单选，可以将准心处的生物丢入佛国中
2. 多选，遍历周围一定范围的生物并自主选择丢入佛国

## 限制
1. 练气期施展最多影响到筑基期
2. 其它情况下只能对和自己同境界或低于自己境界的目标施展

## 表现方式
1. 发出去的信息，只有施法者/自己/和自己在同一个“手掌”中的玩家能接收到
2. 被攻击方只能接收到来自自己/和自己在同一个“手掌”中的玩家/世界的网络包
3. 维度是幽灵维度，服务端全是空气，维度客户端是幽灵，但要能正常交互，让客户端以为不是幽灵方块。这样就能防止玩家在里面刷物品
