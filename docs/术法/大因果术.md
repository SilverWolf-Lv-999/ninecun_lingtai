## 逆天道，避因果，诸般枷锁困于我；顺天道，成因果，今日方知我是我。诸般枷锁本是梦，无形无质亦无我

# 一、功能设计
1. 必中——所有攻击必定攻击到目标，如用远程武器攻击末影人，末影人即使瞬移走也会受到伤害。
2. 钓鱼必定钓到好东西
3. 宝箱开启时获得更好的物品的概率大幅度提高
4. 推衍因果
5. 怪物的AI发现玩家的距离缩小，圆满后完全无法察觉到玩家
6. 坚守者无法听到玩家造成的声音，也无法嗅探到玩家

# 二、因果线推衍设计
1. 对着玩家释放法术时，查看他干过的事情。
2. 对着空气释放右键，查看所有玩家的因果
3. 学习程度越高，可往后推衍的时间就越多

# 三、UI设计与法术设计
1. 对着玩家释放
    1. 打开界面，背景模糊入场
   2. 一条金色、发光的陡峭的线从左侧逐渐衍生入场，上面有一个个节点
   3. 玩家点击节点时，线渐隐退场，玩家在那个时间节点附近做过的事情以文件的形式，一句句浮现，且浮现的坐标不同
   4. 按下esc退出，文字渐隐退场，线渐隐入场
2. 直接释放法术
   1. 打开界面，背景模糊入场
   2. 可以看当前所在界域中的所有玩家，以文字的形式逐个浮现
   3. 左键点击后可以查看，界面与对着玩家右键相同

# 四、约束
1. 只有圆满才能完整的查看所有的事情。否则只能推衍一小段，境界越高也能推衍越长的时间节点
2. 不到仙级的玩家推衍仙级的玩家会直接死亡
