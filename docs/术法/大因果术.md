## 逆天道，避因果，诸般枷锁困于我；顺天道，成因果，今日方知我是我。诸般枷锁本是梦，无形无质亦无我

# 一、功能设计
1. 必中——所有攻击必定攻击到目标，如用远程武器攻击末影人，末影人即使瞬移走也会受到伤害。
2. 钓鱼必定钓到好东西
3. 宝箱开启时获得更好的物品的概率大幅度提高
4. 推衍因果
5. 怪物的AI发现玩家的距离缩小，圆满后完全无法察觉到玩家
6. 坚守者无法听到玩家造成的声音，也无法嗅探到玩家

# 二、因果线推衍设计
1. 对着玩家释放法术时，查看他干过的事情。
2. 对着空气释放右键，查看所有玩家的因果
3. 学习程度越高，可往后推衍的时间就越多

# 三、UI设计与法术设计
1. 对着玩家释放
    1. 打开界面，背景模糊入场
   2. 一条金色、发光的陡峭的线从左侧逐渐衍生入场，上面有一个个节点
   3. 玩家点击节点时，线渐隐退场，玩家在那个时间节点附近做过的事情以文件的形式，一句句浮现，且浮现的坐标不同
   4. 按下esc退出，文字渐隐退场，线渐隐入场
2. 直接释放法术
   1. 打开界面，背景模糊入场
   2. 可以看当前所在界域中的所有玩家，以文字的形式逐个浮现
   3. 左键点击后可以查看，界面与对着玩家右键相同
3. 入口界面设计
   1. 将两个界面用一条线分开，上方的点在左侧向右1/3处，下方的点在右侧向做1/3处，成为左右两个部分
   2. 左方为大应该术的配置，右方为推衍因果，其文字皆在其所在区域中心
   3. 鼠标移动到上面时，文字会稍亮并微微上浮

# 四、约束
1. 只有圆满才能完整的查看所有的事情。否则只能推衍一小段，境界越高也能推衍越长的时间节点
2. 不到仙级的玩家推衍仙级的玩家会直接死亡

# 五、圆满后获得的特殊功能，有开关用于开启和关闭(我为什么要设计这个)
1. 换因果
   1. 将攻击转接到别的玩家身上
   2. 将仇恨转接到别的玩家身上
   3. 渡天劫时将天劫也转接到别的玩家身上，好处自己拿
   4. 获得效果时，如果是负面效果，也转接到别的玩家身上
   5. 玩家攻击村民时，村民的涨价效果转移到别的玩家身上
   6. 受到伤害时，将伤害转移到别的玩家身上
   7. 有选定玩家和随机玩家两种形式
2. 无因得果w
   1. 无视因，直接获得一个注册表里有的随机物品(这就是果)
3. 篡改因果
   1. 玩家获得有益的效果时，将该效果变成随机的有弊的效果
   2. 玩家获得物品时，将物品转移到自己身上
   3. 玩家获取成就/进度时，将该成就/进度转移成自己获取
   4. 玩家合成配方时，合成出的物品变成空气
   5. 有选择玩家与随机玩家两种形式

约束：无法影响到仙级玩家
