# 阵禁篇：神魂刻印与天地为局

> 版本：v1.0（2026-08-13）
> 适用分支：master（net.seraphina 包结构）
> 关联文档：`docs/仙途总纲.md`（本文是其 7.2 戒指禁制与 8.3 阵法两节的完整展开）、`docs/一些基础设定.md`、`docs/五行相生.md`、`docs/灵石.md`
> 定位：禁制与阵法的**完整可实施设计**。核心命题只有一句：**禁制是神魂刻上去的**。由此推出全部体系——神念是稀缺资源、有布必有破、攻防是生态而不是开关。

---

## 一、设计目标与原则

1. **阵禁同源**：禁制与阵法共用一套本质——神魂为魂（规则与锁）、灵力为血（能量）、结构为骨（几何与材料）。器物禁制是微缩的阵，大阵是铺开的禁。
2. **神念是稀缺资源**：一个人的魂魄有限，能分出去的神念就有限。禁制不是刻越多越好，是**分配**问题——随身法宝、储物戒指、洞府大阵抢的是同一份神念。魂修路线由此获得独立价值。
3. **有布必有破，破法不止一种**：任何禁制与阵法都有力破（碾压）、巧破（技艺）、耗破/器破（资源）三条路。没有绝对安全，只有代价高低——这是硬核六律"世界有敌意"的攻防落地。
4. **布与破都是玩法而非菜单**：布阵要动手摆几何，刻禁要做仪式，破禁要解锁纹，破阵要找生门。全程无进度条数字（信息敬畏，沿用炼丹"无进度提示"原则）。
5. **服务端权威、数据驱动**：阵图是数据包 JSON（同丹方/功法），禁制是物品 NBT；判定全在服务端，客户端只发意图与谜题输入。

## 二、概念框架

```
                     神魂刻印（本质）
                          │
        ┌─────────────────┼─────────────────┐
     器禁（物品级）     地禁（空间级）      阵法（空间级）
     刻在戒指/法宝     刻在洞府/区域       阵盘+阵旗+阵图
     纯神念维持        必须以阵法为骨      灵力驱动的能量结构
        │                 │                 │
        └────────┬────────┘                 │
                 │      地禁 = 阵法（骨）+ 禁制刻印（魂）
                 │                          │
                 └──────────┬───────────────┘
                            ▼
                    洞府（阵禁体系的毕业考）
```

- **器禁**：刻在单件物品上的规则锁。轻、快、随身，强度全看刻印者神魂。
- **阵法**：以阵器为节点、灵力为能源的区域效果系统。可独立运转（聚灵阵不需要禁制）。
- **地禁**：把禁制刻进阵法的"点睛"步骤，让区域获得规则（拒入、警报、幻象）。无阵不成地禁。

## 三、神念锚位：整个体系的资源母体

### 3.1 锚位模型

- 每名玩家的**神念锚位总数 = 魂强星数 × 2**（1 星 2 个，7 星 14 个）。
- 每一道维持中的刻印占用锚位：

| 刻印 | 占用锚位 |
| --- | --- |
| 器禁每一层 | 1 |
| 地禁点睛（阵法品阶 1-3 阶） | 2 |
| 地禁点睛（4-6 阶） | 3 |
| 地禁点睛（7 阶以上） | 4 |

- 锚位占满则无法再刻；主动废除自己的刻印可收回锚位（内容物完好，废除需本人触碰目标 5 秒）。
- **魂伤联动**：魂伤 ≥ 50（魂魄震荡）时，超出 `当前可用锚位 = 总锚位 × (1 − 魂伤/200)` 的刻印从最新往旧依次休眠（禁制暂时失效！）——重伤的修士连自家戒指都锁不牢，这是魂伤真正可怕的地方。

### 3.2 刻印即分魂

- 刻印消耗：灵力（按品阶）+ **温养进度 5 × 禁制品阶**（刻禁是拿魂魄成长换安全，取舍有痛感）+ 30 秒仪式。
- 神念是"活"的：
  - 主人魂强提升后，可回炉重刻升级强度；
  - 主人**魂飞魄散**（本局终结）：其全部刻印进入 7 游戏日的衰减期，期满自动崩解——尸骨未寒，遗产窗口；
  - 主人正常死亡（可复活的死）：刻印保持，但见 3.3 死契规则。

### 3.3 死契规则（杀人夺宝的时间博弈）

主人死亡瞬间，其身上掉落物品的禁制自动进入**死契状态**：强度 ×1.5，持续 3 游戏日。

- 效果：杀人者当场破不开（除非境界碾压），要么蹲守死契期满，要么带着"烫手"的戒指跑路——3 日内主人复活后传讯禁仍然生效，能感知戒指方位。
- 依据：文学里"杀人夺宝也要看敢不敢拿"的桥段；游戏上给被杀者一个复仇缓冲窗口，杀人夺宝从"秒杀秒拿"变成一场持续数日的追逃叙事。

## 四、器禁：类型与叠层

### 4.1 六种基础禁制

| 禁制 | 品阶 | 效果 | 典型用途 |
| --- | --- | --- | --- |
| 认主禁 | 一阶 | 非主人无法使用/打开 | 一切的基础层 |
| 传讯禁 | 一阶 | 被触碰/被破解时主人收到"心头一悸"（方向 + 模糊距离，不给坐标） | 失窃感知 |
| 隐匿禁 | 二阶 | 该物品对神识探测隐形（对抗 4.2 神识搜刮） | 藏最值钱的那件 |
| 反噬禁 | 三阶 | 破解失败瞬间反击破解者魂伤 +15 × 层品阶 | 防盗刺 |
| 自毁禁 | 三阶 | 破解进度越过阈值时湮灭内容物（主人可设阈值 50%-90%） | 宁为玉碎 |
| 遗念禁 | 四阶 | 主人预录一句遗言，禁制被破时以主人口吻发给破解者；同时记录破解者神念指纹供主人查验 | 复仇线索 + 叙事 |

### 4.2 叠层规则

- 同一物品可叠多层禁制（每层占 1 锚位），**上限 = 刻印者魂强星数的一半（向上取整）**：3 星叠 2 层，7 星叠 4 层。
- 破解必须**由外向内逐层剥**，每层独立走一次破解流程；外层不破，里层不可见（破解者事先不知道里面还有几层、有没有反噬——信息敬畏）。
- 叠层顺序自由，策略自现：
  - 稳妥流：传讯（外）→ 认主 → 自毁（内）——早警报，最后防线玉碎；
  - 陷阱流：认主（外）→ 反噬 → 反噬（内）——赌破解者贪心；
  - 隐士流：隐匿单层——神识都扫不到，根本不给你破的机会。

### 4.3 刻印强度

```
禁制强度 = 刻印者魂强 × (1 + 境界序号 × 0.5) × (1 + 0.1 × 已叠层数)
```

刻印完成时快照存 NBT，之后不随主人成长自动变化（要变强需回炉重刻）——抢来的老怪物遗物，禁制强度是他巅峰时的，这就是"上古禁制"的由来。

## 五、破解体系：三条路

### 5.1 力破（境界碾压）

- 破解者魂强 × 境界折算的**破禁力 ≥ 禁制强度 × 4**：一念破尽全部层（保留总纲"高出两大境界秒破"的体验，改为按强度比精确判定）。
- 未达碾压线：按强度比硬磨，耗时 = `60 秒 × 2^(强度差档)`。流程无界面：持续潜行按住，神识硬怼，戒指发光嗡鸣渐强、自己灵力狂泄，倒计时结束破除；中途松手或被打断从头再来。体感像用蛮力掰锁——全世界都听得见。力破**必然触发**反噬禁与自毁禁，蛮力是最贵的路。

### 5.2 巧破（锁纹对弈，核心玩法）

禁制是刻印者的神念织成的锁纹。巧破 = 把自己的神识顺着对方的纹路走一遍而不惊动它。

#### 5.2.1 真实感的拟合原则

每个机制都必须对应"神识开锁"的想象，玩家做的事和修士做的事是同一件事：

| 机制 | 拟合 |
| --- | --- |
| 观察流光找路径 | 读对方神念的"笔迹"——不是背密码，是辨认另一个灵魂的习性 |
| 路径必须按五行相生序走 | 破解就是在对方神念里运转小周天——考的是修士对五行的理解 |
| 界面开启期间灵力持续消耗 | 神识铺在锁上是有代价的，你的灵力池就是你的时限（高修为 = 更从容） |
| 点错节点扣容错 | 两股神念相撞，锁会"惊"——容错就是你的神识比对方细腻多少 |
| 盘面灵光碎片与浑光 | 对方神念的疏漏处与暗桩——锁里也有机缘和陷阱 |
| 随时可主动收手 | 高手摸一下锁就知道自己开不开得了，撤退无伤但留痕（惊扰 +1） |
| 现实世界不暂停 | 界面半透明，身后有没有人走近隐约可见——破解的难，一半在谜题外 |
| 层数未知 | 破完一层才浮现里层，每次继续都是赌 |

**五行经络（知识即钥匙）**：每个节点随机染五行之一，正确路径**必然按相生序循环**（…金→水→木→火→土→金…，起点随机）。推论：懂五行的玩家看一眼节点属性分布，就能排除大片不可能的走法（金节点后面只可能接水节点）——观察（盯流光）与推理（辨五行）双通道解题，谜题考的是对这个世界知识体系的理解，而非反应速度。相应地：

- 假流光也走"看似合理"的相生路径，但会在某一步**跳环**（如金直接跳到木）——细看能抓住破绽，品阶越高破绽越隐蔽；
- 一阶禁制无五行约束（教学锁，人人能开）；二阶起经络规则生效；
- 刻印者是阴阳灵根：锁纹相生序**可逆行**（双向皆通，候选路径翻倍）；混沌灵根：无属性约束（纯观察，无从推理）——稀有灵根的禁制天生难破一头，呼应其万中无一的身价。

#### 5.2.3 难度结构（难在哪，凭什么难）

难度是六个独立来源的叠加，每一个都有拟合依据，绝不靠"节点变多"单维膨胀：

1. **规模**（品阶）：节点数与路径长度——锁本身的精密度。
2. **干扰**（品阶）：假流光数量——刻印者布下的迷踪。真假之辨：真流光经过的节点有"先暗后亮"的呼吸感、移动更平滑；假流光生硬匀速、会在五行序上"跳环"。**辨识度随魂强差缩放**（5.2.4 表），这是"神识细腻程度"的直接体感。
3. **时限**（自身灵力）：不设倒计时，但神识铺在锁上每秒烧灵力。练气小贼看一眼就心疼，金丹盗圣可以慢慢欣赏——同一把锁，不同的人有不同的从容。
4. **处境**（环境压力）：现实不暂停。在死人堆里开、在对方洞府里开、在自家安全屋里开，同一道谜题是三种难度。难度来自处境而非谜题本身，这是硬核的核心设计。
5. **未知**（心理博弈）：层数未知、下层是否反噬禁未知。容错见底时最后一次点击前的那口气，才是这个玩法真正的"难"。
6. **博弈**（高阶专属）：五阶起守纹巡逻逼你规划落子顺序与节奏；支径的额外奖励诱你在得手后继续冒险——锁不再是死物，贪心有价。

上手曲线：一阶认主禁（9 节点、路径 4、1 缕假光、无五行约束）是教学级，新手一两分钟能开——保证"人人会开锁"；二阶起五行经络生效，懂行的开始占便宜；三阶起需要真观察力；五阶以上守纹上岗，没有高魂强就是重雾赌命。**门槛不在会不会玩，在敢不敢开、开不开得起。**

| --- | --- | --- | --- | --- |
| 一阶 | 9 | 4 | 1 | 每 4 秒 |
| 二阶 | 12 | 5 | 2 | 每 5 秒 |

（周期越长 = 每次提示之间等得越久 = 观察的时间成本越高，灵力烧得越多。）

按魂强差（人的规格，破解者 − 刻印者）：

| 魂强差 | 真伪辨识 | 雾区 | 容错 | 滞涩预警 |
| --- | --- | --- | --- | --- |
| ≥ +2 | 真流光带微光晕，一眼可辨 | 无 | 差值 +2 | 有 |
| +1 ~ 0 | 呼吸感 + 平滑度正常可辨 | 无 | 2~3 | ≥0 时有 |
| −1 | 仅剩平滑度微差，需盯多轮 | 30% | 1 | 无 |
| ≤ −2 | 几乎同质，节点亮起瞬间才见 | 全图重雾 | 0 | 无 |

多层叠加：每深一层，节点 +2、假光 +1（外层是门面，里层才是主人的真本事）。

盘内元素：

| 元素 | 出现 | 效果 |
| --- | --- | --- |
| 灵光碎片·显真 | 各品阶 1-3 枚（合计） | 下一轮真流光高亮显示 |
| 灵光碎片·定纹 | 五阶以上概率出现 | 冻结全部守纹 5 秒 |
| 灵光碎片·固辉 | 三阶以上概率出现 | 接下来点亮的 2 个节点立即稳固 |

| 守纹 | 五阶 1 个、七阶起 2 个 | 沿纹路巡逻，每 2 秒熄灭 1 个已点亮的未稳固节点 |
| 支径 | 每层 1-2 条 | 主径破除前可加走：擦指纹 / 读残念 / 预亮下层 3 节，节点数为主径的 60%-80% |

#### 5.2.5 服务端判定与反作弊

- 路径每次进入界面时服务端随机生成，客户端只收渲染帧（哪些线段此刻发光），点击序列回传服务端判定——答案不落客户端。
- 真假流光的渲染差异（呼吸感/平滑度）不可避免地存在于客户端数据中，改装客户端理论上可滤取——这与矿透同级，定位为"服务器规则问题"不做过度工程；严格模式（可选配置）下呼吸相位由服务端逐帧下发，流量换安全，供竞技向服务器开启。
- 五行经络规则公开（写进游戏内典籍），流光时序与跳环位置保密——"规则透明、答案隐藏"，攻略只能教方法不能给答案。

### 5.3 器破（烧钱换命）

- **破禁锥**（炼器产物，消耗品）：一至九阶，直接抵消一层同阶以下禁制，跳过锁纹。高阶锥材料含墓穴产出——盗墓养盗术。
- **五行克制**：禁制刻印时染刻印者主灵根属性；用克制属性的破禁锥（如金克木）效果 ×1.5，被克则 ×0.5——搜刮前先掂量对方灵根，情报有了价值。
- **遮蔽符/遮蔽阵**：截断传讯禁的警报（见 7.3 反制链）——专业盗圣的标配开销。

### 5.4 神念指纹（复仇闭环）

- 任何破解（成功或失败）都在禁制残骸上留下破解者的神念指纹。

| 主人魂强 | 可感知 |
| --- | --- |
| 1-2 星 | 仅知"被人破了" |
| 3-4 星 | 破解者魂强星数 + 大境界 |
| 5-6 星 | 追加主灵根属性 |
| 7 星 | 追加最后一次感知方位（一次性，读后即散） |

- 不直接给玩家名（信息敬畏）——凶手是谁，要靠指纹特征在服务器里自己排查。多人服的悬疑叙事由此而生。

## 六、阵法：三要素与布阵

### 6.1 三要素

| 要素 | 载体 | 说明 |
| --- | --- | --- |
| 阵图（知识） | 数据包 JSON（`data/ninecun_lingtai/formations/*.json`） | 同丹方/功法走稀缺链：黄阶坊市有售，玄阶墓穴掉落，地阶以上孤本。需参悟习得 |
| 阵器（器物） | 阵盘（核心方块，储灵 + 载图）+ 阵旗（节点方块，材料定属性）+ 阵基（建筑级大阵的永久基座） | 炼器产物，品阶决定承载上限 |
| 布阵（技艺） | 玩家按阵图几何要求实地摆放 | 见 6.2，动手玩法 |

### 6.2 几何布阵与精度

- 阵图规定阵旗相对阵盘的**方位角与距离**（如四象阵：四旗分居东南西北，距阵盘 8 格）。
- 摆放精度决定阵法效率：

| 全旗最大偏差 | 效率 |
| --- | --- |
| ≤ 0.5 格 | 120%（毫厘不差，阵威更盛） |
| ≤ 1 格 | 100% |
| ≤ 2 格 | 80%（勉强成阵） |
| > 2 格 | 布阵失败，灵力反冲布阵者（走火入魔判定） |

- 辅助：布阵者手持阵盘潜行时，显示各旗位的半透明幻影指引（对齐即变绿）；但**神识开启时才显示精确偏差**——布阵也吃魂强。
- **五行旗序**：阵旗材料各有属性，沿阵图顺位相邻两旗若成相生序（金→水→木→火→土循环），全阵效率 +20%；出现相克相邻则 −30%。同一张阵图，懂五行的人布出来就是比莽夫的强——摆阵的学问和锁纹的学问是同一套（呼应 5.2.1 五行经络）。

### 6.3 运转、驱阵与阵联

- 灵力来源二选一（阵图规定或阵盘设置）：
  - **储能式**：阵盘内填灵石，耗尽停转——攻防战里"围而不攻耗其灵石"成为战术；
  - **汲灵式**：直接抽取所在区块灵气存量——大阵常开会吸干一片地（联动总纲 7.4 枯竭），洞府选址与阵法开销从此是一门学问。
- 阵法品阶一至九阶对应九境界；点睛者境界低于阵图品阶对应境界则无法激活。
- **驱阵**：阵主身处阵域内时，可消耗自身灵力催动阵法立即触发一次效果（杀伐阵额外打出一轮伤害、护府阵瞬间补一层罩、幻阵立刻重摇出口）——阵法不是摆完就看戏的自动炮台，攻防战里阵主本人就是操阵手，人在阵在。
- **阵联**：点睛后可在同域多阵间写联动规则（"某阵触发时，联动触发另一阵"），每条联动占 1 个神念锚位。护府阵被攻击唤醒杀伐阵、幻阵有人迷路时困灵阵落锁、警报响时遮蔽阵自动开启——阵与阵组合出的连锁反应，是阵道高手和会摆阵的人之间的差距。

### 6.4 阵法类别（首期七阵）

| 阵法 | 品阶 | 类型 | 效果 | 能耗 |
| --- | --- | --- | --- | --- |
| 聚灵阵 | 一阶起 | 生产 | 位势聚灵（见下），阵眼浓度与回复大幅抬升 | 汲取邻区块（拆东墙补西墙，净增益但有代价) |
| 护府阵 | 二阶起 | 防御 | 半球护罩，吸收伤害折算灵力 | 储能式 |
| 困灵阵 | 二阶起 | 控制 | 域内敌对减速、禁缩地成寸/御剑 | 储能式 |
| 杀伐阵 | 三阶起 | 攻击 | 域内持续五行伤害（属性随阵旗材料） | 储能式，高耗 |
| 幻阵 | 三阶起 | 隐匿 | 域内地形对外伪装 + 入侵者迷路（出口随机化） | 汲灵式，低耗 |
| 遮蔽阵 | 四阶起 | 反制 | 屏蔽域内神识探测与传讯禁警报 | 储能式 |
| 引灵阵 | 二阶起 | 辅助 | 为域内丹炉/器炉供灵，炼制环境分 +10% | 汲灵式 |

**聚灵位势**：灵气如水，向低处流。聚灵阵不是凭空 +50% 的魔法数字，而是一套位势模型——每面阵旗"锁"住自身所在处的灵气（锁灵量随旗材品阶），人为压出灵气位势差，四周区块的灵气便顺着势差向阵眼汇流，阵眼成为一片"灵气洼地"，浓度与回复速度随汇入量抬升。推论自然成立：

- 阵旗品阶越高锁灵越多，位势差越陡，汇聚越猛；
- 邻区块存量被持续抽吸（总纲 7.4 枯竭联动），洼地越深，四周越贫瘠——宗门宝地和周边荒山从此有了因果；
- **移旗激灵**：阵主手动拔起一面旗重新插放，触发一次位势重算，阵眼灵气短时暴涨（约 30 秒，冷却 1 游戏时）——突破、结丹的关键时刻，老练的阵主会亲自操旗；
- 修炼用阵与突破用阵配置分化：常开的低耗温养阵，与大日子才激活的高耗爆发阵。

### 6.5 点睛：阵与禁的合体

- 布阵完成后阵法处于**明阵**状态：运转但规则粗放（谁都能进，只按类别生效）。
- 布阵者消耗神念锚位**点睛**后升为**灵阵**：获得规则层——白名单（道友自由出入）、警报（入侵触发心头一悸）、阵联规则（见 6.3）。
- 点睛后的阵即"地禁"。点睛者即阵主，阵主魂伤过重时（3.1 锚位休眠）灵阵退化回明阵——重伤不下火线的阵主，他的洞府正在裸奔。

## 七、破阵：三条路与生门

### 7.1 力破

持续输出打爆阵盘承载：护罩每吸收一点伤害耗对应灵力，阵盘储能见底则全阵崩碎（崩碎演出：全部阵旗依次爆裂）。最笨最贵，但人多力量大——宗门战的正面强攻。

### 7.2 巧破（找生门）

- 每座阵按阵图暗藏一根**生门旗**（布阵时系统在合规旗位中随机指定，阵主自己也不知道是哪根——天机不可尽算）。
- 神识开启时可见阵旗间的灵力流转（复用灵识线渲染）：生门旗的流向存在**细微逆流**，魂强越高逆流越明显（1-2 星几乎不可辨，7 星一眼看穿）。不做任何高亮标记，纯观察力。
- 拔除生门旗：全阵紊乱瘫痪 60 秒（阵主收到剧烈警报），期间可自由出入、阵内规则全失。阵主可在瘫痪期内重插旗恢复（插旗 10 秒仪式）——攻防节奏点。
- 拔错旗：该旗喷灵力反冲（伤害 + 击退），惊扰值 +1；惊扰满 3 次阵法进入戒备（全部灵力流隐藏 1 游戏日，巧破路线关闭）。

### 7.3 耗破与反制链

- **耗破**：储能式阵法怕围困——围而不攻，等灵石烧完。阵主的对策是汲灵式备用阵或囤积灵石，攻方的对策是先用聚灵阵反向抽干守方区块存量（毒计：用生产阵打攻防战）。
- **反制链**（体系间的剪刀石头布）：

```
神识探测 ──克──> 隐匿的洞府     遮蔽阵 ──克──> 神识探测 / 传讯禁
幻阵 ──克──> 踩点侦察           破禁锥(克制属性) ──克──> 高层禁制
杀伐阵 ──克──> 蹲守耗破的围攻者  聚灵阵(攻方) ──克──> 汲灵式防御阵
生门巧破 ──克──> 一切明阵灵阵    高魂强 ──克──> 生门的隐蔽性
```

没有一种布置是绝对安全的，每种布置都明确知道自己怕什么——这就是"极度复杂但每一层都讲理"的攻防生态。

## 八、洞府：阵禁体系的毕业考

- 洞府 = 选址（灵气浓度/质量/存量三优之地）+ 聚灵阵（生产）+ 护府阵（防御）+ 幻阵（隐匿）+ 点睛规则（警报白名单）+ 库房器禁（最后防线）。
- 一座完整洞府吃掉 8-11 个神念锚位——4 星魂强勉强撑起，6 星才从容。修为高深者的洞府才固若金汤，天经地义。
- **离线规则**（多人痛点的正面回答）：阵主离线时护府阵强度 ×2，但灵力只出不进（储能只减不增，汲灵式减半效率）——攻方打离线府邸要啃硬壳但能围死，守方不能靠下线获得绝对安全。离线满 7 游戏日进入"府主远游"状态，强度回落 ×1——长期不上线的洞府终会被攻破，服务器地皮自然流转。
- 洞府被攻破的全服播报："某地一座洞府的防护大阵已然崩碎"——不点名坐标，闻讯赶去分一杯羹的、兔死狐悲的，各自上路。

## 九、体验设计

- **刻禁仪式**：盘坐持物 30 秒，一缕银白神念丝线从眉心缓缓没入物品（粒子），刻成时物品浮起自旋一周、发出一声清鸣。旁观者全程可见——在坊市当众给新宝贝刻禁，本身就是宣示。
- **心头一悸**：传讯禁触发时，主人无论身在何处，屏幕边缘朝事发方向泛起一圈微光涟漪 + 一声心跳，聊天框仅自己可见："你在 [方位] 的一道神念传来惊扰。"距离只给模糊档（咫尺/百里/千里之外）。
- **锁纹对弈**：破解界面星轨纹路缓缓旋转，正确节点的流光走向需要凝神细看；每点亮一节，星轨嗡鸣升调半音——快破完时的音高本身就是紧张感。描错瞬间全图猩红一闪。
- **找生门**：夜色中蹲在大阵外围，开神识凝视灵识线流向，风声里辨认那一缕逆流——这个画面就是修仙文学里"阵法大师斗法"的直译。
- **死契的忌惮**：捡起死契状态的戒指时，物品栏图标缠绕暗红锁链纹，tooltip 只有一句："其主之念，犹未散尽。"

## 十三、风险清单

- **锁纹小游戏的手感**：这是全篇最大的实现风险——谜题要"观察力"而非"背板/手速"，需要先做纸面原型验证再写渲染；保底方案是退化为带容错的节点顺序记忆题。
- **五行经络的知识门槛**：不懂相生序的新手在二阶锁前会撞墙——一阶教学锁必须把"金生水"的规则用流光演示喂到嘴边（游戏内典籍 + 锁纹界面首次提示），且纯观察路线始终可行（推理只是捷径不是门槛）。
- **守纹与支径的复杂度膨胀**：两者都只在中高阶出现，首期实现可以砍掉（进阶包后补），锁纹主循环不依赖它们。
- **几何校验的服务端成本**：布阵校验只在放置/激活时做一次，运转期不重复校验；旗被破坏走方块破坏事件驱动。
- **锚位休眠的体验**：魂伤导致禁制休眠必须给明确提示（心头钝痛 + 提示语），否则玩家会以为是丢档。
- **离线保护的平衡**：×2 强度与 7 日回落两个参数决定服务器地皮流转速度，必须进配置由服主调。
- **神念指纹的隐私边界**：只给特征不给名字的原则不可破，否则悬疑感变点名册。
- **与既有系统的耦合顺序**：锚位挂魂强、刻印耗温养、休眠看魂伤——神魂三件套（已实装）必须先于本篇任何步骤上线。
