# 储物戒指
## 设计：
1. 右键打开界面，底下为玩家物品栏，顶部一大块范围进行交互，玩家看到的是一小块世界空间
2. 玩家所可以从背包中拿起物品，对范围内进行交互(比如左右键交互等，右键放置箱子，左键破坏方块)
3. 如果玩家放置了箱子，可以通过右键那个箱子打开那个箱子容器的界面
4. 中键长按可以随着鼠标移动旋转摄像机，wasd/shift/space(默认情况下的移动交互)可以让摄像机前后左右、上下移动
5. 玩家范围为5×5

## 实现
1. 玩家初次打开一个储物戒指时，通过数据生成创建一个维度，该维度不会有实体更新
2. 新建个摄像机，将其从0,0开始2个区块范围内的区块，通过摄像机投影到交互处，该范围被框定
3. 玩家可以通过设计上的方式，通过摄像机与该区域交互
4. 一个储物戒指只会绑定一个维度
5. 摄像机无法离开范围
