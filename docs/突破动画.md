## 通用动画逻辑
1. 使用贝塞尔曲线，背景逐渐模糊入场
2. 播放专属动画
3. 专属动画渐隐退场
4. 背景模糊退场

## 设计
1. 是GUI动画，渲染在所有UI的最上层，不是screen
2. 无法用f1隐藏
3. 全部使用着色器渲染
4. 抗锯齿

### 凡人->练气
1. 一滴雨滴从屏幕上方落在屏幕中心，颜色则是根据玩家灵根进行混合
2. 波纹溅起
3. 波纹慢慢变成一个漩涡

### 练气->筑基
1. 漩涡向中心凝固，一个道台浮现
2. 道台稍稍放大随后绽放光芒
3. 道台回到原来大小

### 筑基->金丹
1. 道台先完整存在并持续震颤 2 秒，震颤幅度逐步增强，期间不会提前出现裂纹
2. 2 秒后道台瞬间破裂，裂纹闪光与碎片爆散同时出现
3. 破裂后持续 1 秒剧烈震动，碎片保持外扩并各自旋转
4. 随后在 1.5 秒内以阻尼方式快速平息，平台残影消退，碎片停止剧烈抖动
5. 平息后碎片分别沿独立的旋转吸引轨迹向中心聚集，边移动边进行极坐标扭曲
6. 碎片逐渐由多边形拉伸、圆化为球形并重合，最终形成金丹
7. 金丹稳定后停留 2 秒，表面流光缓慢旋转并散发柔和金色光芒

### 金丹->元婴
1. 金丹先在屏幕中心持续颤抖，颤动幅度逐步增强，随后沿裂纹瞬间碎裂
2. 碎片向外爆散并快速旋转，碎裂闪光与屏幕震动同步出现，随后震动阻尼平息
3. 碎片消散后，莲花从中心的白色灵光中由小到大显性，花瓣带有柔和的青白边缘光
4. 莲花稳定展开后，婴儿轮廓从花心逐渐显性，依次出现头部、衣袍、手足与面部细节
5. 婴儿最终停留在莲花中央，持续散发白色洁光，动画末尾整体渐隐
